# VISERON — La Ascensión de la Superinteligencia

Juego de plataformas del **Trinnity Viseron System (TVS)**. Cada mundo es una
**transformación** del VISERON — crece como la propia superinteligencia:
**MARIO** (plataformas) → **MEGAMAN** (disparo) → **NARUTO** (velocidad) →
**DRAGON BALL** (poder KAME) → **SAINT SEIYA/CDZ** (armadura cosmos) →
**NASA** (espacio). Recoge energía (mentes), gana poder y lanza el TVS al
espacio. Inspirado en los grandes: Mario, Megaman, Naruto, DBZ, CDZ y los
juegos top 3D / NASA.

## Español / ES

### Windows (nativo, Python 3)
```bat
python tools\viseron-game\windows\viserongame.py
```
- **Controles:** ← → mover · ESPACIO saltar · X disparar · ESC salir
- **Demo autónoma** (el VISERON juega solo, muestra lo que somos):
```bat
python tools\viseron-game\windows\viserongame.py --demo 30
```
- Atajo npm: `npm run game:viseron`

### DOS (QBasic)
- Copia la carpeta `tools\viseron-game\dos\` a tu DOS (o un disquete).
- Necesitas `QBASIC.EXE` junto a `VISERON.BAS` (MS-DOS 5+/6/7).
- Escribe `VISERON.BAT` (o `qbasic VISERON.BAS` y pulsa **F5**).
- En Windows usa **DOSBox**: `tools\viseron-game\dos\start-dosbox.bat`
  (con DOSBox instalado; sin él, monta la carpeta y ejecuta `VISERON.BAT`).

## English / EN

### Windows (native, Python 3)
```bat
python tools\viseron-game\windows\viserongame.py
```
- **Controls:** ← → move · SPACE jump · X shoot · ESC quit
- **Autonomous demo** (VISERON plays itself — shows what we really are):
```bat
python tools\viseron-game\windows\viserongame.py --demo 30
```
- npm shortcut: `npm run game:viseron`

### DOS (QBasic)
- Copy `tools\viseron-game\dos\` to your DOS machine (or floppy).

- Type `VISERON.BAT` (or `qbasic VISERON.BAS` and press **F5**).
