// TVS OS

O Sistema Operativo de IA

Camada de SO sobre o kernel: processos, ficheiros virtuais, app store, pacotes e segurança — com desktop web

Process Manager

Spawn de agentes com timeout, estado RUNNING/COMPLETED/FAILED e histórico de 200 processos

Virtual File System

8 raízes virtuais (home, apps, agents, processos, memória, modelos, workspace, system)

App Store

Catálogo de 21 apps (agentes, squads, módulos, skills) com instalar/desinstalar

Package Manager

Instala/desinstala/atualiza pacotes e manifestos, com diagnóstico de saúde (doctor)

Security Center

Permissões por role e trilho de auditoria (500 entradas) em cada autorização

TVS Desktop

Página /os — desktop do sistema operativo no navegador, ligado à API /api/os

tvs — estado do sistema operativo

$ npm run tvs

O TVS OS é o sistema operativo real da superinteligência: lanças processos, lês ficheiros virtuais, instalas apps e pacotes, e toda a ação é auditada — tudo via API /api/os/* ou CLI tvs.

// OMEGA Platform

Arquitetura OMEGA

A espinha dorsal da superinteligência — kernel, runtime, memória, roteamento, autonomia e auto-cura

Kernel + EventBus

Núcleo com bus de eventos, permissões por role e attach de agentes/memória/router

Agent Runtime

10 agentes nucleares carregados de specs com fallback offline e eventos por tarefa

Knowledge Graph

Memória de grafo persistida em ficheiro — entidades, relações e decisões

AI Router

Roteamento por critérios entre ollama, omniroute, openai, claude, gemini e grok

Autonomy Layer

Planeamento, evolução e aprendizagem ligados ao planner/engines do core

AIOX Squads

5 manifestos de squad (engineering, security, operations, business, research)

Factory Engine

Pipeline de 4 stages para gerar soluções e scaffolds a partir de specs

Enterprise Hub

6 módulos empresariais (sales, support, finance, marketing, ops, product)

Self-Heal Watchdog

5 alvos vigiados — destrava componentes presos e regista incidentes automaticamente

Gateway /api/omega

Command Center + endpoints de kernel, runtime, memória, autonomia, squads, factory, enterprise e watchdog
