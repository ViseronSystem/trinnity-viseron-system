# Site Público da Campanha

Este diretório será usado para um site institucional e informativo, com:

- Biografia autorizada da candidata.
- Propostas baseadas em fontes públicas.
- Agenda pública e canais oficiais.
- Formulário de contacto voluntário com consentimento.
- Política de privacidade e aviso de uso de dados.
- Identificação de publicidade e responsável, quando aplicável.
- Prestação de contas e correções públicas.

Não incluirá segmentação oculta, pixel para inferir opinião política, coleta de bases compradas ou publicação automática sem revisão humana.

## WhatsApp permitido

Podemos integrar a API oficial do WhatsApp apenas para contactos que deram opt-in, com mensagem identificada, limite operacional, registro de consentimento e opção de saída. Não será criado disparador de spam para 100 mil contactos.
