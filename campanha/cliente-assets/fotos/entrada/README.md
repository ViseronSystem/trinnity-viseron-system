# Entrada de Fotos da Cliente

Coloque aqui somente imagens autorizadas pela candidata ou pelo titular dos direitos.

## Antes de enviar

- Confirmar autorização de uso, finalidade, prazo e canais de publicação.
- Não enviar documentos, listas de eleitores, capturas de bases de dados ou imagens de menores sem autorização específica.
- Não usar as imagens para inferir raça, religião, saúde, renda, orientação sexual, opinião política ou outras características sensíveis.
- Informar o nome do ficheiro, data, fotógrafo, direitos de uso e contexto pretendido.
- Não incluir segredos, tokens, passwords ou dados pessoais desnecessários.


1. Enviar as imagens originais nesta pasta.
2. Registrar a autorização em `campanha/auditoria/decisoes.md`.
3. A equipe revisa qualidade, direitos e finalidade.
4. Só depois uma cópia aprovada pode ir para o site ou materiais públicos.

As imagens não serão usadas para criar perfis de eleitores ou listas de contacto.
